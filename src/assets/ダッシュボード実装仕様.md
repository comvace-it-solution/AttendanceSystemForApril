# ダッシュボード実装仕様

## 目的

このドキュメントは、`画面一覧.md` と `機能一覧.md` の内容をプログラミングで参照しやすい形に変換した実装仕様である。

対象画面は `A-1002 ダッシュボード画面` とする。

## 画面概要

本画面は、当日の勤務状況と従業員の現在状態を確認するためのダッシュボード画面である。

ログインユーザーは勤務サマリーで自身の現在状態、実働時間、休憩時間を確認できる。また、勤務状態に応じて出勤、休憩開始、休憩終了、退勤の打刻操作を行う。

従業員の出勤状況一覧では、従業員ごとの勤務状態、出勤時刻、休憩開始時刻、休憩終了時刻、退勤時刻を確認できる。

## 画面構成

### ルート構成

| 領域 | コンポーネント名の例 | 役割 |
| --- | --- | --- |
| 画面全体 | `DashboardPage` | 初期表示、状態管理、API実行、各表示領域の統合を行う。 |
| ヘッダー | `DashboardHeader` | 画面タイトル、説明文、表示日付を表示する。 |
| 勤務サマリー | `AttendanceSummary` | ログインユーザーの現在状態、実働時間、休憩時間を表示する。 |
| 打刻操作 | `PunchActions` | 出勤、休憩開始、休憩終了、退勤ボタンを表示し、状態に応じて活性制御する。 |
| 出勤状況一覧 | `AttendanceList` | 従業員ごとの現在状態と打刻時刻を一覧表示する。 |
| メッセージ | `MessageBar` | API成功・失敗時のメッセージを表示する。 |

## データモデル

### AttendanceStatus

```ts
type AttendanceStatus = "出勤前" | "勤務中" | "休憩中" | "退勤済み";
```

### 勤務状態の表示条件

データベース上の現在の勤怠状態は `current_attendance_state` で管理する。

`current_attendance_state` は `1 = 勤務中`、`2 = 休憩中`、`null = 非勤務中` の3パターンである。

画面側では、最新の勤務終了日時 `work_end_dt` と組み合わせて以下の4パターンで表示する。

`work_end_dt` は日時項目のため、判定では時刻までの完全一致ではなく、日付部分が対象日と一致するかで当日判定を行う。

| 画面表示状態 | 判定条件 |
| --- | --- |
| 出勤前 | `current_attendance_state` が `null` かつ、最新の `work_end_dt` が当日の日付ではない、または `work_end_dt` が存在しない場合 |
| 勤務中 | `current_attendance_state` が `1` の場合 |
| 休憩中 | `current_attendance_state` が `2` の場合 |
| 退勤済み | `current_attendance_state` が `null` かつ、最新の `work_end_dt` が当日の日付である場合 |

```ts
type AttendanceSummary = {

## API仕様

設計書上のAPI名を実装向けに整理する。

| 処理 | API名 | メソッド例 | 目的 |
| --- | --- | --- | --- |
| 勤怠一覧取得 | `fetchAttendanceList` | `GET` | ログインユーザーの勤務サマリー、および従業員ごとの勤怠情報を取得する。 |
| 従業員一覧取得 | `fetchEmployees` | `GET` | 出勤状況一覧に表示する従業員情報を取得する。 |
| 勤務開始 | `clockIn` | `POST` | 出勤前のユーザーを勤務中にする。 |
| 休憩開始 | `startBreak` | `POST` | 勤務中のユーザーを休憩中にする。 |
| 休憩終了 | `endBreak` | `POST` | 休憩中のユーザーを勤務中に戻す。 |
| 勤務終了 | `clockOut` | `POST` | 勤務中のユーザーを退勤済みにする。 |

### APIレスポンス例

#### 勤怠一覧取得

type FetchAttendanceListResponse = {

    breakEndTime: string | null;
    clockOutTime: string | null;
  }>;
};
```

#### 従業員一覧取得

```ts
type FetchEmployeesResponse = Array<{
  userId: string;
  userName: string;

```

#### 打刻API

```ts
type PunchResponse = {
  success: boolean;
};
```

## 初期表示処理

### 処理フロー

1. 画面表示時に当日の日付を生成する。
2. `fetchAttendanceList` を実行する。
3. `fetchEmployees` を実行する。
4. 従業員一覧と勤怠一覧を `userId` で結合し、`usersList` を生成する。
5. `summary` と `usersList` を画面に反映する。
6. 取得に失敗した場合はエラーメッセージを表示する。

### 疑似コード

```ts
async function initializeDashboard() {
  setLoading(true);
  clearMessage();

  try {
    const [attendance, employees] = await Promise.all([
      fetchAttendanceList(),
      fetchEmployees(),
    ]);

    setSummary(attendance.summary);
    setUsersList(mergeAttendanceUsers(employees, attendance.attendanceList));
  } catch {
    setMessage({
      type: "error",
      text: "出勤状況一覧の取得に失敗しました。しばらく経ってから、再度お試しください。",
    });
  } finally {
    setLoading(false);
  }
}
```

## 打刻処理

### 共通処理

打刻API成功後は、勤務サマリーと出勤状況一覧を再取得する。

```ts
async function executePunch(action: PunchAction) {
  clearMessage();
  setLoading(true);

  try {
    await action();
    await initializeDashboard();
    setMessage({
      type: "success",
      text: "打刻処理に成功しました。",
    });
  } catch {
    setMessage({
      type: "error",
      text: "出勤処理に失敗しました。しばらく経ってから、再度お試しください。",
    });
  } finally {
    setLoading(false);
  }
}
```

### ボタン別処理

| ボタン | 実行条件 | 実行API | 成功後の状態 |
| --- | --- | --- | --- |
| 出勤 | `current_attendance_state === null` かつ最新の `work_end_dt` が当日の日付ではない、または `work_end_dt` が存在しない | `clockIn()` | `current_attendance_state` が `1` となり、画面表示状態は勤務中 |
| 休憩開始 | `current_attendance_state === 1` | `startBreak()` | `current_attendance_state` が `2` となり、画面表示状態は休憩中 |
| 休憩終了 | `current_attendance_state === 2` | `endBreak()` | `current_attendance_state` が `1` となり、画面表示状態は勤務中 |
| 退勤 | `current_attendance_state === 1` かつ休憩終了後 | `clockOut()` | `current_attendance_state` が `null` となり、最新の `work_end_dt` が当日の日付となるため、画面表示状態は退勤済み |

## ボタン活性制御

```ts
function getPunchButtonState(status: AttendanceStatus, hasBreakEnded: boolean) {
  return {
    canClockIn: status === "出勤前",
    canStartBreak: status === "勤務中",
    canEndBreak: status === "休憩中",
    canClockOut: status === "勤務中" && hasBreakEnded,
  };
}
```

### 注意点

設計書では退勤条件が「勤務中（休憩終了後）」となっている。休憩なしで退勤を許可するかどうかは設計書だけでは確定できないため、実装時は業務ルールとして確認する。

## 項目別入力チェック一覧

本画面で使用する入力チェックは以下の通りとする。

| No. | 項目名 | 必須 | チェック内容 | チェック結果 |
| --- | --- | --- | --- | --- |
| 1 | 出勤ボタン | ◯ | 画面表示状態が「出勤前」であること。`current_attendance_state` が `null` かつ、最新の `work_end_dt` が当日の日付ではない、または `work_end_dt` が存在しない場合に「出勤前」と判定する。 | 出勤ボタンが活性状態となり、押下後に `current_attendance_state` が `1` へ更新され、画面表示状態が「勤務中」へ移行する。 |
| 2 | 休憩開始ボタン | ◯ | 画面表示状態が「勤務中」であること。`current_attendance_state` が `1` の場合に「勤務中」と判定する。 | 休憩開始ボタンが活性状態となり、押下後に `current_attendance_state` が `2` へ更新され、画面表示状態が「休憩中」へ移行する。 |
| 3 | 休憩終了ボタン | ◯ | 画面表示状態が「休憩中」であること。`current_attendance_state` が `2` の場合に「休憩中」と判定する。 | 休憩終了ボタンが活性状態となり、押下後に `current_attendance_state` が `1` へ更新され、画面表示状態が「勤務中」へ移行する。 |
| 4 | 退勤ボタン | ◯ | 画面表示状態が「勤務中」であり、退勤可能条件を満たすこと。`current_attendance_state` が `1` かつ、休憩終了後である場合に退勤可能と判定する。 | 退勤ボタンが活性状態となり、押下後に `current_attendance_state` が `null` へ更新される。最新の `work_end_dt` が当日の日付となるため、画面表示状態は「退勤済み」へ移行する。 |
