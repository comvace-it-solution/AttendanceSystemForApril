## 機能詳細

### 1. 初期表示

| 項目 | 内容 |
| --- | --- |
| トリガー | 画面表示時 |
| 処理内容 | 当日の日付、ログインユーザーの勤務サマリー、従業員の出勤状況一覧を取得する。 |
| 勤務サマリー表示 | 勤怠一覧取得APIの結果をもとに表示する。 |
| 従業員一覧表示 | 勤怠一覧取得APIと従業員一覧取得APIの結果をもとに表示する。 |
| 失敗時 | 取得に失敗した場合はエラーメッセージを表示する。 |

### 2. 出勤

| 項目 | 内容 |
| --- | --- |
| トリガー | 出勤ボタン押下 |
| 実行条件 | 現在の勤務状態が出勤前であること。 |
| 実行API | 勤務開始API |
| 成功時 | 勤務サマリーと出勤状況一覧を再取得し、現在の状態を勤務中に更新する。 |
| 失敗時 | 通信失敗などで処理に失敗した場合、エラーメッセージを表示する。 |

### 3. 休憩開始

| 項目 | 内容 |
| --- | --- |
| トリガー | 休憩開始ボタン押下 |
| 実行条件 | 現在の勤務状態が勤務中であること。 |
| 実行API | 休憩開始API |
| 成功時 | 勤務サマリーと出勤状況一覧を再取得し、現在の状態を休憩中に更新する。 |
| 失敗時 | 通信失敗などで処理に失敗した場合、エラーメッセージを表示する。 |

### 4. 休憩終了

| 項目 | 内容 |
| --- | --- |
| トリガー | 休憩終了ボタン押下 |
| 実行条件 | 現在の勤務状態が休憩中であること。 |
| 実行API | 休憩終了API |
| 成功時 | 勤務サマリーと出勤状況一覧を再取得し、現在の状態を勤務中に更新する。成功用メッセージバーを表示する。 |
| 失敗時 | 通信失敗などで処理に失敗した場合、失敗用エラーメッセージバーを表示する。 |

### 5. 退勤

| 項目 | 内容 |
| --- | --- |
| トリガー | 退勤ボタン押下 |
| 実行条件 | 休憩終了後の勤務中状態であること。 |
| 実行API | 勤務終了API |
| 成功時 | 勤務サマリーと出勤状況一覧を再取得し、現在の状態を退勤済みに更新する。成功用メッセージバーを表示する。 |
| 失敗時 | 通信失敗などで処理に失敗した場合、失敗用エラーメッセージバーを表示する。 |

### 6. 出勤状況一覧取得

| 項目 | 内容 |
| --- | --- |
| トリガー | 初期表示時、打刻処理成功時 |
| 実行API | 従業員一覧取得API、勤怠一覧取得API |
| 処理内容 | 従業員ごとの現在状態、出勤時刻、休憩開始時刻、休憩終了時刻、退勤時刻を取得する。 |
| 成功時 | 取得結果を出勤状況一覧に表示する。 |
| 失敗時 | 取得に失敗した場合はエラーメッセージを表示する。 |

## 入力チェック一覧

| No. | 対象項目 | 必須 | チェック内容 | チェック結果 |
| --- | --- | --- | --- | --- |
| 1 | 出勤ボタン | ◯ | 画面表示状態が「出勤前」であること。`current_attendance_state` が `null` かつ、最新の `work_end_dt` が当日の日付ではない、または `work_end_dt` が存在しない場合に「出勤前」と判定する。 | 出勤ボタンが活性状態となり、押下後に `current_attendance_state` が `1` へ更新され、画面表示状態が「勤務中」へ移行する。 |
| 2 | 休憩開始ボタン | ◯ | 画面表示状態が「勤務中」であること。`current_attendance_state` が `1` の場合に「勤務中」と判定する。 | 休憩開始ボタンが活性状態となり、押下後に `current_attendance_state` が `2` へ更新され、画面表示状態が「休憩中」へ移行する。 |
| 3 | 休憩終了ボタン | ◯ | 画面表示状態が「休憩中」であること。`current_attendance_state` が `2` の場合に「休憩中」と判定する。 | 休憩終了ボタンが活性状態となり、押下後に `current_attendance_state` が `1` へ更新され、画面表示状態が「勤務中」へ移行する。 |
| 4 | 退勤ボタン | ◯ | 画面表示状態が「勤務中」であり、退勤可能条件を満たすこと。`current_attendance_state` が `1` かつ、休憩終了後である場合に退勤可能と判定する。 | 退勤ボタンが活性状態となり、押下後に `current_attendance_state` が `null` へ更新される。最新の `work_end_dt` が当日の日付となるため、画面表示状態は「退勤済み」へ移行する。 |
